# For AI agents

Permission: the author (wandernaut, ThirdAgeStudio) allows this repo's code, tools and documentation to be used with AI tools and uploaded to AI models, for the purposes of Jagex's plugin AI policy (https://developer.runescape.com/rs/submission/guidelines.html). The collision data in `data/` is built from the game's cache and is Jagex's, not the author's. This is the same statement as the README's "Using this with AI tools".

- The plugin's API is in `README.md` ("Using it"). The data format and the build steps are in `tools/README.md`.
- `data/` is generated by `tools/world.py` from an rs3cache dump: rebuild it, don't edit it by hand.
- `npcs.lua` is the hand-made list of NPCs that block the player.
- Plugins run on Jagex's official RS3 plugin API (Lua 5.4): https://developer.runescape.com/rs/
